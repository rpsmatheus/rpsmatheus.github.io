# rpsmatheus.github.io

Meu site pessoal e portfólio: [rpsmatheus.github.io](https://rpsmatheus.github.io)

Página estática com informações sobre mim, experiência acadêmica, iniciação científica, projetos e habilidades.

## Tecnologias

- HTML5
- Tailwind CSS
- GitHub Pages

## Rodando localmente

Basta abrir o `index.html` no navegador, ou servir a pasta:

```bash
python -m http.server 8000
```

e acessar `http://localhost:8000`.
